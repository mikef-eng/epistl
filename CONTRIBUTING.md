# Contributing to Epistl

Epistl is in **active early development**. Thank you for your interest.

## Pull requests

**We are not accepting pull requests at this time.** External PRs are closed automatically with a pointer back here. Development is driven by an internal AI agent harness (see [AGENTS.md](AGENTS.md)); outside code contributions would bypass that flow.

When we open up to external code contributions, this document will change.

## What we do accept

- **Bug reports** — use the [Bug report](https://github.com/mikef-eng/epistl/issues/new?template=bug_report.yml) form
- **Feature requests** — use the [Feature request](https://github.com/mikef-eng/epistl/issues/new?template=feature_request.yml) form

Please do **not** file security vulnerabilities as public issues. See [SECURITY.md](SECURITY.md).

## Running locally

To explore or reproduce a bug on your machine:

1. Follow [`packages/dev-setup/README.md`](packages/dev-setup/README.md) (two-stage bootstrap).
2. Read [`docs/architecture/overview.md`](docs/architecture/overview.md) for stack wiring.

Do not open a PR with local fixes — file an issue instead.
